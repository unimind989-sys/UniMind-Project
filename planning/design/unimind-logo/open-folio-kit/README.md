# Open Folio integration dependency

Ahmed supplied `unimind-open-folio-kit/` and authorized integration on 1 October
2026 (Cairo). This directory preserves the selected production SVG variants,
all supplied icons, both integration guides and their approval/license/provenance
records. The original supplied directory is untouched.

The supplied manifest describes the complete original kit, including builder,
proof sheets and additional exports that are intentionally not copied here.
It remains the source of asset hashes and logo approval provenance; it is not
an application approval or a claim that this subset is the complete package.

Runtime copies are under `public/brand/unimind/`. Next's icon, favicon and Apple
icon files are exact supplied copies. Application styling and responsive usage
are governed by [DESIGN.md](../../../../DESIGN.md), [usage-guide.md](usage-guide.md)
and [integration.md](integration.md).
