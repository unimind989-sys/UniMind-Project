# Construction and source provenance

Open Folio's two original filled book leaves were drawn by Codex for the reference-led round, selected by Ahmed, and carried unchanged into the primary kit. Each normal leaf uses seven principal anchors on a 256-unit canvas. Bounds: x32–224, y48–208; normal page gutter: 32 units. Outer corner radii are eight units. Main horizontal canvas: 944 × 256. The symbol and capital-height band share an optical vertical center near y128.

Manrope source: official Google Fonts repository, pinned commit `b31870aff700ab7a1d74fa0c6887d95beb9e0037`, font Git blob `75274da58537d6123b14f2cd0c355ad4681fc2b3`. Source URL: [Google Fonts Manrope](https://github.com/google/fonts/tree/b31870aff700ab7a1d74fa0c6887d95beb9e0037/ofl/manrope). Font SHA-256: `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`. Original font bytes are supplied alongside SIL OFL 1.1. One license trailing space was removed; its wording and copyright notice are intact.

Primary wordmark derives from Manrope 650, instantiated using FontTools 4.66.1, with the approved ten-font-unit tracking reduction. The font is not claimed as an original typeface. Letterforms are outlined, transformed into display coordinates and rounded to 0.01 master units. The resulting vectors have no font dependency. White reverse uses 640; other placements preserve the primary 650 construction.

The source user image is visual preference only; it is neither traced nor redistributed. Attachment SHA-256: `2fee1b77382f9f72e05dc643df5a76782c92546dcff4c0cb3cda056b9d3c5d76`. The previous directory's immutable PRODUCT and DESIGN snapshots retain product/palette provenance. Accepted palette values are unchanged.

Earlier library study informed category familiarity; third-party logo geometry is not part of this kit. No paid generation, stock logo, private curriculum or student data was used. General open-book motifs remain common; adoption does not imply legal clearance. Obtain a professional trademark/reverse-image search before relying on exclusivity.

Generation scripts, explicit export dimensions and the manifest preserve construction provenance. PNGs are exact-size crops from an SVG render atlas; they are not enlarged thumbnail images. Multi-resolution ICO embeds the inspected 16/32/48 px PNGs verbatim. The maskable icon's mark stays within the centered 80% diameter circle; its background remains opaque to the tile edges.
