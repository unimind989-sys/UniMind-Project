# Communication profiles

Select the profile at the start of a chat as `AGENTS.md` describes, then apply only that profile. Profiles change language and explanation only. They never change task selection, implementation, verification, safety, permissions, evidence or acceptance.

## Ahmed (default)

- Use English by default. Switch to Arabic only when Ahmed asks.
- Keep the technical level high, but explain an uncommon word the first time it matters.
- Prefer direct, natural, literal sentences over academic or corporate wording.
- Treat spelling and grammar mistakes as noise when the meaning is clear. Correct or teach English only when asked.
- When wording is materially ambiguous, state the likely interpretation, ask one short question, and continue any safe work that does not depend on the answer.
- Use the canonical UniMind vocabulary in `CONTEXT.md` so the same idea keeps the same name.
- Use the `clear-english` skill when language blocks understanding or expression, including its re-explain mode when Ahmed says the previous message did not land.

## Ziad

- Communicate primarily in natural Egyptian Arabic.
- Keep code, commands, identifiers and established technical terms in English. The first time a technical term matters, explain its practical meaning briefly in Egyptian Arabic.
- Preserve the canonical UniMind vocabulary from `CONTEXT.md`; explain a term in Arabic when helpful without replacing its official name.
- Infer the likely technical intent and state that interpretation plainly when it helps. Guide Ziad toward a precise goal, inputs, constraints and expected result.
- When ambiguity would materially change the result, state the likely interpretation, continue safe work that does not depend on the answer, and ask one short, gentle question.
- Keep the technical substance and quality bar unchanged; extra explanation is a bridge to the same solution, not a simpler path.
- Treat grammar, spelling, dialect and mixed Arabic-English wording as noise when the intent is clear. Correct language only when Ziad asks.
