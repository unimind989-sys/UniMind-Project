# Skill behavior checks

Use these cases after changing a skill's description, invocation mode, or a workflow it depends on. Judge the decision, not exact wording. Manual skills trigger only on explicit invocation (`$name` in Codex, `/name` in Claude Code). When a demonstrated failure leads to a skill change, add the case that would have caught it.

| Skill | Should trigger | Should not trigger |
| --- | --- | --- |
| `finalize` | `Implement WP03-T04 from the runbook.` reaches a stable candidate: deliver through PR, exact-head CI, merge, affected production proof, closure, and cleanup under D-22 without a second message. A provider call that may cost $3.00 stops before the mutation with the exact exposure named. | `Implement this, local only.` stops at the local boundary and records the remaining action; no PR, merge, or approval prompt for a zero-cost step. |
| `trust-boundaries` | `Change ownership resolution for signed storage URLs.` records the trust map and proves one allowed and one forbidden path; the candidate gets an independent review. | `Add a heading to the signed-in dashboard.` (code that merely runs after login). |
| `tdd` | `Implement the documented catalog resolver contract test-first.` names the established seam and proceeds without asking. | `A unit test failed because the expected literal is stale.` (ordinary edit loop). |
| `codebase-design` | `Design two interfaces for this policy module.` generates distinct alternatives with deep-module terms; at most one read-only challenger. | `Rename this variable inside the existing module.` |
| `domain-modeling` | `We keep saying "course" and "unit" for the same thing; settle it.` challenges the terms and updates `CONTEXT.md`. | `Implement the quiz route using the existing glossary terms.` |
| `diagnosing-bugs` | `This intermittent performance regression survives two focused attempts; diagnose it.` builds a red-capable loop first. | `One focused unit test failed with a clear stack trace pointing at a typo.` |
| `grilling` | `Grill me on the first pilot cohort plan.` runs numbered question rounds with recommended answers. | `What is the current pilot cohort size?` (a fact the agent can look up). |
| `clear-english` | `Wait, what? I didn't follow that.` re-explains the previous message in the seven-step re-pitch. `What does idempotent mean here?` defines it with one UniMind example. | `Implement WP01-T02 from the runbook.` with minor typos (no grammar correction, no language detour). |
| `unslop` | `Rewrite this README section so it sounds natural, but keep every requirement.` edits prose and checks semantic drift. | `Show the raw JSON evidence exactly as stored.` |
| `skill-authoring` | `The TDD skill made us test an internal method again; fix it.` passes the evidence gate, patches narrowly, runs `pnpm skills:sync` and `pnpm lint:agents`, and logs the change. | `A unit test failed after my code change.` (no evidence the skill caused it). |
| `frontend-design` | `Design the empty state for the new quiz review screen.` works inside `DESIGN.md` and the Cobalt direction with CSS Modules. | `Implement a queue retry policy.` (backend only). |
| `impeccable` | `Audit app/student/page.tsx.` runs the audit with the pinned Vercel rules and deduplicates findings. `Critique the study shelf.` runs the read-only assessments. | `Correct one clipped label in the Study Shelf.` (frontend quality floor only). `Generate three new visual directions with comps.` (new-work and image generation are disabled; route to `frontend-design` and the founder). |
| `blast-radius` | `$blast-radius Compare this branch with main.` resolves the fixed point, traces indirect contracts, and runs a focused proof. | `Could this migration affect workers?` without invocation (answered normally). |
| `image-to-code` | `/image-to-code Implement this attached desktop mockup exactly.` inventories the image, builds through existing seams, and compares in the built-in browser at desktop and mobile. | `Build this written dashboard brief; there is no mockup.` |
| `logo-design` | `$logo-design Explore three original logo directions.` shows tested concepts and waits for a founder choice before the kit. | `Could the current logo work at favicon size?` without invocation. |
| `wizard` | `/wizard Configure the Supabase dashboard and GitHub secrets for me.` separates human-only steps and drafts PowerShell after confirming stages. | `Configure the Supabase dashboard and GitHub secrets for me.` without invocation (explain the human-only steps instead). |
